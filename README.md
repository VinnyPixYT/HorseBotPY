# horse bot

A Discord bot with economy, counting games, levels, and tree planting features.

## Features

- **Counting Game** - Count numbers in channels
- **Level/XP System** - Earn XP by chatting
- **Tree Planting** - Plant and water virtual trees
- **Economy** - Work, rob, gamble, and manage money

## Commands

- `/ping` - Test bot responsiveness
- `/hello` - Get a greeting
- `/activity-counting` - Manage counting games
- `/activity-levels` - Manage levels and XP
- `/activity-tree` - Manage tree activities
- `/activity-economy` - Manage economy

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Create a `.env` file with your Discord bot token:
   ```
   DISCORD_TOKEN=your_token_here
   ```

3. Run the bot:
   ```
   python bot.py
   ```

## IMPORTANT NOTICE

> This bot is designed to function in only one server. You may only **locally** change the code to work in a designated server of your choice.
